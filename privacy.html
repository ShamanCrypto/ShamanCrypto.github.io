Privacy policy

Last updated: 28 October 2026

gmail-mcp is a personal tool used only by its owner, for the owner's own Gmail accounts. It has no other users.

What data it accesses

With the owner's consent, through the Gmail API, it accesses messages, labels and basic settings of the owner's own Gmail accounts.

How the data is used

Data is used only to carry out tasks the owner asks for, such as searching, reading or sending the owner's email. Message content is passed to the AI assistant the owner uses only when the owner asks for it.

Storage

Access tokens are stored only on the owner's own computer. The tool runs no server and keeps no copy of email data.

Sharing

Data is not sold, used for advertising, or shared with anyone else.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
